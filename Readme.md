# Prediction System – Hospital Readmission & Clinical Text Analysis

This project is my complete end-to-end **Prediction System**, built as part of the RLDatix Data Science assignment.  
It predicts whether a patient will be readmitted to the hospital within 30 days and extracts key information from discharge notes using NLP.

---

## Project Overview

The goal of this project was to build an AI assistant that can:
1. Predict 30-day readmission risk using patient data.  
2. Extract and categorize important terms like diagnosis, symptoms, treatments, medications, and follow-up actions from discharge summaries.

I combined both structured and unstructured data to show how clinical notes can help improve prediction performance.
